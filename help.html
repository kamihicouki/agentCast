agentCast 使い方ガイド

気になる記事やフォロー中のSNS・ニュースから、2人掛け合いのラジオ番組を自動作成して聴ける Chrome 拡張機能です。

START 基本の3ステップ

STEP 01

AI・音声を設定する

「設定」タブで Gemini API キー（または OpenAI API キー）を入力します。まずは音声だけでも試したい場合は「デモ番組を試聴」が使えます。

STEP 02

記事やソースを取り込む

「巡回」タブで 今のタブを取り込む か、複数タブ・X/Zenn/Note などの巡回ソースを有効にします。

STEP 03

番組を作成して聴く

「聴く」タブの 巡回して番組を作成・再生（または素材キューから作成）を押すと、台本と音声が自動生成されます。

各タブの役割

  • 聴く： ワンクリックでの巡回＆番組作成、再生プレイヤー（再生速度・チャプター切替・台本ハイライト）、過去番組一覧、書き出し（音声 / HTML / Markdown / 動画）を行えます。
  • 巡回（巡回ソース / 素材キュー）： 今開いている記事1本だけを取り込んだり、タブグループ・カスタムサイト・SNS/ニュースをまとめて収集できます。「素材キュー」では集めた記事を取捨選択して番組化できます。
  • 設定： 外観テーマ、サイドパネルの表示範囲、AIモデル・APIキー、読み上げ音声（Gemini TTS / OpenAI TTS / ローカル音声）、番組の尺や自動巡回スケジュールを設定できます。

TIPS 快適に使うためのヒント

  • サイドパネルを閉じても生成・再生は続きます： 番組作成や音声再生はバックグラウンドで動作します。サイドパネルを閉じている間も、Chrome ツールバーの拡張機能アイコンに 45%（進行中）や OK（完了）、!（エラー）のバッジが表示されます。
  • 他作業の邪魔になるときは「開いたタブのみ」表示に： 「設定」タブの サイドパネルの表示範囲 を「開いたタブのみ」に変更すると、他のタブへ切り替えた際にサイドパネルが自動で隠れます。
  • 進捗%と残り時間について： 生成中はプログレスバー・進捗%・経過時間・残り時間の目安が表示されます。外部AIの応答速度により目安時間は前後することがあります。

よくある質問・トラブルシューティング

Q. 「Gemini台本生成エラー (503)」が表示されました

Google Gemini サーバーが一時的に混雑している状態です。agentCast は自動で最大数回の再試行と代替モデル（gemini-2.5-flash）への切り替えを行いますが、それでも失敗する場合は少し時間をおくか、「設定」タブで別のモデルへ変更してお試しください。失敗しても素材キューの記事は消えずに残ります。

Q. 記事をたくさん読み込ませると時間がかかります

記事数が多いほど台本生成と音声合成に時間がかかります。まずは1〜3記事程度で試し、必要に応じて「素材キュー」から記事数を絞るか、番組の尺を短め（3〜5分）に設定するのがおすすめです。

Q. 音声合成が失敗したり遅い場合は？

クラウドTTS（Gemini TTS / OpenAI TTS）が一時的に使えない場合でも、自動的にブラウザ標準のローカル音声（Web Speech）へフォールバックして再生できます。「設定」タブからいつでも音声エンジンを切り替えられます。
