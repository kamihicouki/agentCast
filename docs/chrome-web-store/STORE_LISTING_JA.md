# Chrome Web Store 掲載情報・審査回答（agentCast 0.6.1）

## 基本情報

- 拡張機能名（マニフェスト） `agentCast — Personal Podcast Reader`
- カテゴリ 仕事効率化 › ワークフローと計画
- 言語 日本語
- 概要（マニフェスト） フォロー中のSNS・ニュース・技術記事を自身のブラウザセッションで読み取り、2人掛け合いの個人用ラジオ番組に編成して再生するChrome拡張機能。

## 詳細説明

```
agentCast は、指定した記事・タブグループ・購読ソースを、2人の掛け合いで聴ける日本語ポッドキャストにまとめます。

■ 設定から再生まで
1. 設定：ご自身の Gemini API（Cloud Billing 有効）または OpenAI API キーと、音声エンジンを設定します。番組の長さは3〜30分、またはおまかせから選べます。
2. 巡回：フォロー中のSNSや動画サイト、ニュース・技術ブログなどの購読ソース、登録した HTTPS サイト（フィードや更新履歴、記事ページ）、開いているタブやタブグループから素材を集めます。
3. キュー：番組に含める素材を選択して生成します。定時生成を有効にすると、指定時刻に巡回し、未読キューから対象素材を選びます。過去番組との重複を整理し、続報を取り上げます。
4. 再生：サイドパネルで台本を追いながら聴けます。音声ファイルや閲覧用ドキュメントの保存、Markdown 台本のコピーに対応し、作成した番組の共有や投稿準備にも使えます。

■ プライバシーとデータ送信
・最初にサイドパネルでデータ取り扱いを説明し、同意を得ます。受動収集と定時生成は既定で OFF です。受動収集を有効にした場合は、許可した HTTPS サイトの登録範囲に限り、閲覧時に素材をキューへ保存します。
・台本生成では、素材のタイトル・URL・日時・本文抜粋、番組設定、直近番組の見出し・要約を、設定した公式 AI API（Gemini API または OpenAI API）へ直接送信します。動画要約では字幕などの動画情報、クラウド音声合成では生成した台本を送信します。
・API キーは Chrome 内で暗号化して保存し、対応する AI API への認証に使います。設定・キュー・台本・音声もローカル保存です。開発者へのデータ送信・トラッキング・データ販売はありません。
```

## 単一用途

> ユーザーが指定した Web ページ・タブ・購読ソースの素材から、自身の AI API キーで日本語ポッドキャストの台本と音声を生成し、ブラウザ内で再生・共有するための拡張機能です。定時生成を有効にすると、許可済みソースを指定時刻に巡回して未読素材から番組を作成します。

## 権限が必要な理由

| 権限 | 審査フォーム向けの説明 |
|---|---|
| `storage` | 同意、ユーザーの設定、巡回ソース、受動収集の設定、暗号化した API キーを拡張機能のローカル領域に保存します。 |
| `unlimitedStorage` | 生成したポッドキャスト音声（WAV / MP3）と台本、動画要約、素材を IndexedDB にローカル保存します。音声ライブラリは通常の容量制限を超えることがあります。 |
| `sidePanel` | 作業中のタブを残したまま、プレイヤー、台本、キューと設定をサイドパネルに表示します。 |
| `offscreen` | サイドパネルを閉じても音声再生と Chrome のメディア操作を維持します。 |
| `alarms` | 定時生成を明示的に有効にしたユーザーの指定時刻に、巡回と番組作成を開始します。既定は OFF です。 |
| `tabs` | 巡回タブを開閉し、ユーザー指定のタブ・タブグループ・YouTube 動画の URL とタイトルを取得します。 |
| `tabGroups` | 巡回用タブを専用グループにまとめ、ユーザーが選んだタブグループから素材を取り込みます。 |
| `scripting` | 操作対象の許可済み HTTPS ページから素材を抽出します。受動収集が明示的に有効な場合は登録先に限定して実行し、AI Studio や公開フォームの補助にも使います。 |
| ホスト権限 | 固定権限は `https://generativelanguage.googleapis.com/*` と `https://api.openai.com/*` で、ユーザーの API キーによる台本生成・動画要約・音声合成と接続確認に使います。任意ホスト権限 `https://*/*` は、巡回・タブ取り込み・受動収集・サイト上の補助に必要な HTTPS ホストだけを実行時に要求するために使います。 |

ストア ZIP は `activeTab`、HTTP の任意ホスト権限、マニフェストの自動注入対象を含みません。実行するコードは ZIP 内に同梱されます。

## データ使用

- 個人を特定できる情報（公開先設定や購読先から取得する名前、ユーザー名、ハンドル）
- 認証に関する情報（ユーザーの Gemini / OpenAI API キー）
- ウェブ履歴（ユーザーが取り込んだページの URL・タイトル等）
- ウェブサイトのコンテンツ（記事本文、字幕・動画情報、リンク等）
