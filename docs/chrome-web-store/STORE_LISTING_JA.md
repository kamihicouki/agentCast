# Chrome Web Store 掲載情報＆審査回答テンプレート（agentCast）

## 基本情報
- **拡張機能名**: `agentCast — Personal Podcast Reader`
- **カテゴリ**: 仕事効率化（Productivity）
- **言語**: 日本語（主言語）
- **概要（132文字以内）**:
  > 選んだニュース・技術記事・タブグループを2人掛け合いの日本語ポッドキャストに編成し、Chrome サイドパネルでながら聴きできる個人用AIラジオ拡張機能。

## 詳細説明（ストア掲載文）
```
agentCast は、あなたが明示的に選んだ Web 記事・タブグループ・ニュース・YouTube 新着をまとめ、自然な2人掛け合いの日本語ラジオ番組として再生できる個人用 AI ポッドキャスト拡張機能です。

■ 4ステップのシンプルなワークフロー
1. 設定：お持ちの Gemini API または OpenAI API キー、音声エンジン、好みの番組尺（3〜30分スライダー／おまかせ）を設定。
2. 巡回：X・YouTube・Note・Zenn・Yahoo!ニュース・Google News や任意のカスタムサイト（RSS / Changelog / Readability / CSS指定）、開いているタブ・タブグループから、明示的な操作で最新素材を収集。
3. キュー：集まった素材を確認し、番組に含めるアイテムだけを個別に選択。長さスライダーをその場で調整して番組を作成（古い情報・過去番組との重複は自動整理、続報は採用）。
4. 再生：ライブラリ＆プレイヤー画面で、再生中はハイライト追従する掛け合い台本を読みながら快適にながら聴き。WAV / HTML / Markdown 保存にも対応。

■ プライバシー＆明示的同意ベース
・新規インストール時、閲覧中の自動収集（受動ストック）は既定で OFF です。明示的に ON にするまで、ページを開いただけで本文読み取りやキュー保存を行うことはありません。
・AI プロバイダ（Gemini API / OpenAI API）へ送信されるのは、ユーザーがキューで選択した素材のテキストと番組設定のみです。
・開発者サーバーへのデータ送信・トラッキングは一切なく、設定・APIキー・台本・音声はすべてローカルブラウザ内にのみ保存されます。
```

## Chrome Web Store 審査「プライバシーと権限」回答テンプレート

### 単一目的（Single Purpose）
> ユーザーが明示的に指定・選択した Web ページ・タブグループ・購読ソースのテキストを抽出し、ユーザー自身の AI API キーを用いて日本語ポッドキャスト番組（台本および音声）に編成してブラウザ内で再生すること。

### 各権限の正当性説明（Permission Justifications）
※ 実際の `dist/agentCast-v0.5.1-cws.zip` 内 `manifest.json` の全権限と 1対1 で一致しています。

| 権限 | 審査フォーム貼り付け用説明 |
|---|---|
| `storage` | ユーザーの設定（AI プラン・番組の好み・巡回対象サイト・API キー・既定 OFF の受動収集フラグ）を `chrome.storage.local` に保存するために使用します。 |
| `unlimitedStorage` | 生成したポッドキャスト音声データ（WAV / MP3 Blob）および台本ライブラリをブラウザ内の IndexedDB に容量制限で消えることなくローカル保存するために使用します。 |
| `sidePanel` | 作業中のタブを妨げず、ながら聴きプレイヤー・台本・キュー・巡回設定をサイドパネルに表示するために使用します。 |
| `offscreen` | Side Panel を閉じたりタブを移動したりしても、ポッドキャスト音声再生と MediaSession（Bluetooth イヤホン操作等）を途切れさせないために使用します。 |
| `alarms` | ユーザーが定時自動生成を明示的にオンにした場合のみ、指定時刻に番組作成をトリガーするために使用します。 |
| `tabs` | ユーザーの明示的な操作による巡回タブの開閉、選択タブグループの URL 取得、開いている YouTube 動画 URL の取得のために使用します。 |
| `tabGroups` | 巡回用タブを視覚的に分かりやすい専用グループ（「agentCast 巡回中」）にまとめ、またユーザーが選択したタブグループ内のページを一括でキューへ取り込むために使用します。 |
| `scripting` | ユーザーが「巡回」「今のタブを取り込む」「タブグループ → キューへ」等の操作を実行した際に、対象ページから記事本文を抽出するコンテンツスクリプトをオンデマンド実行するために使用します。 |
| `activeTab` | ユーザーが「今のタブを取り込む／番組化」を押した際に、現在アクティブなタブの本文を読み取るために使用します。 |
| `host_permissions` (`https://generativelanguage.googleapis.com/*`, `https://api.openai.com/*`) | ユーザーが設定した自身の API キーを用いて、選択素材の台本生成・動画要約・音声合成を公式 API へ直接リクエストするために使用します。 |
| `optional_host_permissions` (`https://*/*`, `http://*/*`) | ユーザーが巡回・タブグループ取り込み・カスタムサイト登録を実行する際、対象オリジンに対してのみオンデマンドでアクセス許可を求めるために使用します（`<all_urls>` は要求しません）。 |
| `content_scripts` | **空配列（`[]`）**。ページ閲覧だけで自動注入されるコンテンツスクリプトは含まれていません。 |
| リモートコードの使用 | **いいえ（使用しません）**。すべての JavaScript は拡張機能パッケージ内に同梱されています。 |

### データ取り扱い（Data Usage）チェック項目
- **開発者によるデータ収集**: 収集しない（開発者サーバーなし。設定・キュー・台本・音声はすべてローカル保存）
- **外部送信先**: ユーザーが自ら設定した公式 AI API（Google Gemini API / OpenAI API）へ、ユーザーが選択した素材テキストと番組設定のみを直接送信
- **受動収集**: 新規インストール時は既定 OFF（明示的なオプトインまで本文読み取り自体を開始しない）
- **データの第三者販売・広告利用**: いいえ
