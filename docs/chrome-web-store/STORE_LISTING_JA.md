# Chrome Web Store 掲載情報＆審査回答テンプレート（agentCast）

## 基本情報
- **拡張機能名**: `agentCast — Personal Podcast Reader`
- **カテゴリ**: 仕事効率化（Productivity）
- **言語**: 日本語（主言語）
- **概要（132文字以内）**:
  > フォロー中のニュース・技術記事・YouTube新着を2人掛け合いの日本語ポッドキャストに自動編成し、Chrome サイドパネルでながら聴きできる個人用AIラジオ拡張機能。

## 詳細説明（ストア掲載文）
```
agentCast は、あなたが普段チェックしているニュース・技術ブログ・SNS・YouTube 登録チャンネルの最新情報をまとめ、自然な2人掛け合いの日本語ラジオ番組として再生できる個人用 AI ポッドキャスト拡張機能です。

■ 4ステップのシンプルなワークフロー
1. 設定：Gemini API / OpenAI API（お持ちのキー）と音声エンジン、好みの番組尺（3〜30分スライダー／おまかせ）を設定。
2. 巡回：X・YouTube・Note・Zenn・Yahoo!ニュース・Google News や任意のカスタムサイト（RSS / Changelog / Readability / CSS指定）をフラットに一元管理。YouTube 登録チャンネルの「動きあり／なし」チェックや、動画の「見る／流し見／スキップ」要約判定にも対応。
3. キュー：集まった最新素材（過去番組との重複・古い情報を自動除外、続報は採用）を個別調整し、その場で長さをスライド指定して番組を生成。
4. 再生：ライブラリ＆プレイヤー画面で、再生中はハイライト追従する掛け合い台本を読みながら Bluetooth イヤホン等で快適にながら聴き。WAV / HTML / Markdown 保存にも対応。

■ プライバシー最優先の設計
・開発者サーバーへのデータ送信やトラッキングは一切ありません。
・設定・APIキー・生成した台本と音声はすべてお使いの Chrome ブラウザ内（ローカル）のみに保存されます。
・台本生成・音声合成は、あなたが設定した Gemini API または OpenAI API へ直接通信します。
```

## Chrome Web Store 審査「プライバシーと権限」回答テンプレート

### 単一目的（Single Purpose）
> ユーザーが指定した Web ページ・ニュース・購読ソースのテキストを抽出し、個人の AI API キーを用いて日本語ポッドキャスト番組（台本および音声）に編成してブラウザ内で再生すること。

### 各権限の正当性説明（Permission Justifications）
| 権限 | 審査フォーム貼り付け用説明 |
|---|---|
| `sidePanel` | 作業中のタブを妨げず、ながら聴きプレイヤー・台本・巡回設定を常時表示するために使用します。 |
| `offscreen` | Side Panel を閉じたりタブを移動したりしても、ポッドキャスト音声再生と MediaSession（Bluetooth イヤホン操作等）を途切れさせないために使用します。 |
| `storage` | ユーザーの設定（AI プラン・番組の好み・巡回対象サイト・API キー）をローカルに保存するために使用します。 |
| `alarms` | ユーザーが定時自動生成をオンにした場合のみ、指定時刻に番組作成をトリガーするために使用します。 |
| `activeTab` | ユーザーが「今のタブを取り込む／番組化」を押した際に、現在表示中のページ本文を読み取るために使用します。 |
| `scripting` | ユーザーが指定した巡回対象ページやアクティブタブから記事本文・メタデータを抽出するコンテンツスクリプトをオンデマンド実行するために使用します。 |
| `tabs` | ユーザーの指示による巡回タブの開閉、および開いている YouTube 動画 URL の取得のために使用します。 |
| `tabGroups` | 巡回用タブを視覚的に分かりやすい専用グループ（「agentCast 巡回中」）にまとめ、またユーザーが選択したタブグループを一括番組化するために使用します。 |
| `host_permissions` (`generativelanguage.googleapis.com`, `api.openai.com`) | ユーザーが設定した自身の API キーを用いて、台本生成および音声合成を公式 API へ直接リクエストするために使用します。 |
| `optional_host_permissions` (`https://*/*`, `http://*/*`) | ユーザーが任意に追加したカスタムサイト・RSS フィードを読み取る際、必要なドメインに対してのみ権限を付与するために使用します。 |
| リモートコードの使用 | **いいえ（使用しません）**。すべての JavaScript は拡張機能パッケージ内に同梱されています。 |

### データ取り扱い（Data Usage）チェック項目
- 開発者によるデータ収集：**収集しない**（すべてローカル保存＋ユーザー設定の公式 AI API への直接送信のみ）
- データの第三者販売・広告利用：**いいえ**
