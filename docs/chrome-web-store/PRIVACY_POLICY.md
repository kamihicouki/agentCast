# agentCast プライバシーポリシー

最終更新日: 2026年11月20日

**agentCast — Personal Podcast Reader**（以下「本拡張機能」）は、ユーザーのプライバシーを最優先に設計されています。本拡張機能の開発者は、ユーザーの閲覧履歴・記事本文・API キー・生成された台本および音声データを収集、保存、販売、または第三者へ共有することはありません。

## 1. 読み取り開始の原則（明示的な操作・同意ベース）
- **新規インストール時の既定動作**: 閲覧中の自動受動ストック（パッシブ収集）は**既定で OFF** です。ユーザーが設定画面で明示的に ON にするまで、ページ閲覧だけで本文抽出やキュー保存は開始されません。
- **手動操作による読み取り**: ユーザーが「巡回を実行」「今のタブを取り込む」「タブグループ → キューへ」「動画を要約」などの操作を明示的に実行した場合に限り、対象ページの本文・タイトル・URL・公開日時等のテキストを抽出します。
- **AI 送信対象の限定**: キュー画面から番組を生成する際は、**ユーザーがチェック選択した素材のみ**（および重複回避のための直近過去番組の見出し・要点）が AI へ送信されます。未選択の素材や閲覧中の別タブの内容は送信されません。

## 2. 取り扱うデータと保存場所
本拡張機能が扱うすべてのデータは、ユーザーのローカルブラウザ内（`chrome.storage.local` およびブラウザ内 IndexedDB）にのみ保存されます。

- **ユーザーが設定した情報**: AI プロバイダ設定、API キー（Gemini / OpenAI）、番組の好み（長さ・パーソナリティ名・関心トピック）、巡回対象サイト・監視チャンネル設定、公開先アカウント設定。
- **抽出したテキストおよび生成物**: ユーザーの明示的な操作（または明示的に有効化した受動ストック）によって取得した記事・投稿テキスト、および生成された番組台本・音声データ。

## 3. 外部サービスへの通信と送信データ
本拡張機能は開発者の独自サーバーを持たず、以下の通信のみをユーザーのブラウザから直接実行します。

1. **AI 台本生成・動画要約・音声合成（ユーザーが設定した公式 API へ直接送信）**
   - Google Gemini API (`https://generativelanguage.googleapis.com/*`)
   - OpenAI API (`https://api.openai.com/*`)
   - 送信データ: ユーザーが選択した素材のタイトル・URL・本文抜粋・日時、番組設定（長さ・関心トピック・パーソナリティ名）、重複回避用の直近エピソード要約。
2. **ユーザーが明示的に指示した対象サイト・公開フィードへのアクセス**
   - ユーザーが巡回・動画要約・フォロー確認を実行した際、対象サイト（カスタムサイト・タブグループ・Zenn RSS・YouTube 公開チャンネル RSS / 動画ページ等）へブラウザから直接アクセスしてテキストを取得します。
3. **ユーザーが任意で「キー半自動取得」「YouTube / X 公開補助」を押した場合**
   - `aistudio.google.com` / `studio.youtube.com` / `x.com` のタブを開き、フォーム入力補助のみを行います（最終的な作成・公開ボタンの自動クリックは行いません）。

外部 API および各 Web サイトでのデータ取り扱いは、各提供事業者のプライバシーポリシーおよび利用規約に従います。

## 4. 使用する権限とその目的
- `storage` / `unlimitedStorage`: ローカル設定・未読キュー・番組台本および音声データ（IndexedDB）をブラウザ内に保持するため。
- `sidePanel` / `offscreen`: サイドパネルでの操作およびタブ切替に依存しないバックグラウンド音声再生（MediaSession 含む）のため。
- `alarms`: ユーザーが定時自動生成を明示的に ON にした場合のみ、指定時刻に番組作成を実行するため。
- `activeTab` / `scripting` / `tabs` / `tabGroups`: ユーザーが明示的に指示したタブ・タブグループ・巡回対象ページからの本文抽出、および巡回タブのグルーピングのため。
- `host_permissions` (`https://generativelanguage.googleapis.com/*`, `https://api.openai.com/*`): ユーザー設定の公式 AI API へ直接リクエストするため。
- `optional_host_permissions` (`https://*/*`, `http://*/*`): ユーザーが巡回・タブ取り込み・カスタムサイト登録を実行する際に、必要なオリジンに対してのみオンデマンドでアクセス許可を求めるため。

## 5. データの削除
本拡張機能の設定や保存データ（キュー・番組・API キー）は、拡張機能内の削除操作または Chrome から本拡張機能をアンインストールすることで、いつでも完全に削除できます。
