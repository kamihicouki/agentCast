# agentCast プライバシーポリシー

最終更新日: 2026年11月19日

**agentCast — Personal Podcast Reader**（以下「本拡張機能」）は、ユーザーのプライバシーを最優先に設計されています。本拡張機能の開発者は、ユーザーの閲覧履歴・記事本文・API キー・生成された台本および音声データを収集、保存、販売、または第三者へ共有することはありません。

## 1. 取り扱うデータと保存場所
本拡張機能が扱うすべてのデータは、ユーザーのローカルブラウザ内（`chrome.storage.local` およびブラウザ内 IndexedDB）にのみ保存されます。

- **ユーザーが設定した情報**: AI プロバイダ設定、API キー（Gemini / OpenAI）、番組の好み（長さ・パーソナリティ名・関心トピック）、巡回対象サイト・監視チャンネル設定、公開先アカウント設定。
- **抽出したテキストおよび生成物**: ユーザーの明示的な操作（巡回実行・タブ取り込み・受動ストック有効時の閲覧）によって取得した記事・投稿テキスト、および生成された番組台本・音声データ。

## 2. 外部サービスへの送信
本拡張機能は、番組台本の生成・動画要約・音声合成を実行するために、ユーザーが自ら設定した以下の公式 API エンドポイントへ必要なテキストのみを直接送信します。開発者の独自サーバーを経由することはありません。

- Google Gemini API (`https://generativelanguage.googleapis.com/*`)
- OpenAI API (`https://api.openai.com/*`)

外部 API への送信内容は、各提供事業者のプライバシーポリシーおよび利用規約に従って取り扱われます。

## 3. 権限の利用目的
- `sidePanel` / `offscreen`: サイドパネルでの操作およびタブ切替に依存しないバックグラウンド音声再生。
- `storage` / `alarms`: ローカル設定・番組ライブラリの保存、およびユーザーが有効にした場合の定時自動生成。
- `activeTab` / `scripting` / `tabs` / `tabGroups`: ユーザーが指定したタブ・タブグループ・巡回対象ページからの本文抽出。
- `optional_host_permissions`: ユーザーが追加・有効化したサイトに対する読み取り権限のオンデマンド取得。

## 4. データの削除
本拡張機能の設定や保存データ（キュー・番組・API キー）は、拡張機能内の削除操作または Chrome から本拡張機能をアンインストールすることで、いつでも完全に削除できます。
