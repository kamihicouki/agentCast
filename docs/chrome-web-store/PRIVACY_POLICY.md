# agentCast プライバシーポリシー

最終更新日 2026年11月20日
対象 Chrome Web Store 版 agentCast — Personal Podcast Reader（0.6.1 以降）

agentCast は、指定した Web ページ・購読ソースを日本語ポッドキャストにまとめる Chrome 拡張機能です。開発者は利用者のデータを受信するサーバーを運用しておらず、トラッキング、広告配信、データ販売を行いません。

## 1. 取り扱う情報と同意

- 初回利用時に拡張機能のサイドパネルに表示する説明を読み、「データの取り扱いに同意して続ける」を押すと利用を開始できます。「設定」から同意を取り消せます。取り消した後は、次に同意するまで新規の巡回・抽出・外部 AI への新規リクエストが止まります。送信済みのデータには送信先のポリシーが適用されます。
- **手動巡回とタブの取り込み**。ユーザーが選んだソース・ページ・タブグループから、タイトル、URL、公開日時、本文・字幕などの素材、購読先の名前とハンドルを取得します。手動のキュー生成ではチェックした素材を使い、「このソースだけで番組化」や「今のタブを即番組化」ではその操作の対象素材を使います。
- **定時巡回と番組生成**。新規インストール時は OFF です。有効にすると、設定した時刻に許可済みのソースを巡回し、未読キューから鮮度・重複・件数を考慮して対象素材を自動選択します。
- **閲覧中の受動収集**。新規インストール時は OFF です。全体設定とカスタムサイトごとの受動収集を有効にすると、アクセスを許可した HTTPS サイトの登録範囲内を閲覧したときに抽出スクリプトを実行し、素材をキューに保存します。RSS 専用の登録先は受動収集の対象外です。
- 番組の長さ・関心トピック・話者設定、ソースと公開先の設定、API キー、キュー、動画要約、台本・音声を Chrome プロファイル内に保存します。API キーは AES-GCM で暗号化し、暗号鍵は当該拡張機能のローカル IndexedDB に保存します。

## 2. 外部通信、送信先と送信する情報

| 操作 | 送信先とデータ |
|---|---|
| 台本生成 | ユーザーが設定した Google Gemini API（`generativelanguage.googleapis.com`）または OpenAI API（`api.openai.com`）に、対象素材のタイトル・URL・日時・本文抜粋、番組設定、重複を避けるための直近番組の見出しと要約を HTTPS で送信します。 |
| YouTube 動画要約 | 取得できた字幕または動画の概要・タイトル・チャンネル名・長さと、関心トピックを AI API に送信します。Gemini で動画そのものを要約するときは、動画 URL も送信します。 |
| クラウド音声合成 | 設定した Gemini API または OpenAI API に、生成した台本の発話内容と音声設定を送信します。ローカル音声を選んだ場合は、クラウド音声合成への送信は行いません。 |
| API 認証・接続テスト | Gemini のキーは Google へ `x-goog-api-key`、OpenAI のキーは OpenAI へ `Authorization: Bearer` ヘッダーで送信します。AI Studio のキー取得補助では、ユーザーの操作でキーを拡張機能へ取り込み、Gemini API で疎通確認してからローカルに保存します。 |
| 巡回・購読先の確認 | 許可した対象サイトや RSS/Atom フィードに HTTPS でアクセスします。X・YouTube のフォロー先確認や動画情報の取得では、ユーザーが Chrome で利用しているサイトのログイン状態を使用する場合があります。サイトへの通常の通信による Cookie の送信先は当該サイトです。Cookie を AI API に渡す処理はありません。 |
| 番組の共有・公開補助 | ユーザーが共有を選ぶと、番組情報や音声を選択した共有先に渡します。YouTube Studio・X の公開補助では、操作した投稿先に投稿文や動画を渡します。最終的な投稿・公開はユーザーが操作します。 |
| ローカル出力 | WAV・HTML・MP4 は利用者の端末に出力します。台本と参照リンクは Markdown 形式でクリップボードにコピーします。 |

Gemini には [Cloud Billing が有効なプロジェクトのキー](https://aistudio.google.com/docs/terms#paid-services) を使用してください。OpenAI API では [モデル改善へのデータ共有](https://developers.openai.com/api/docs/guides/your-data) をオフにしてください。各送信先での処理・保持には、そのサービスの条件が適用されます。

## 3. Chrome Web Store の制限付き使用

agentCast によるユーザーデータの利用は、Chrome Web Store のユーザーデータポリシーと [制限付き使用（Limited Use）の要件](https://developer.chrome.com/docs/webstore/program-policies/limited-use) に従います。取得したデータとその派生データは、利用者に示したポッドキャスト機能の提供と、その機能のために利用者が指定した送信先への必要な送信に限って使用します。開発者による第三者販売、広告利用、信用力の判断や融資目的への利用、データの閲覧は行いません。

## 4. Chrome の権限

- `storage`、`unlimitedStorage`。設定、キュー、要約、番組、音声を拡張機能のローカル領域に保存します。
- `sidePanel`、`offscreen`。サイドパネルにプレイヤーと設定を表示し、閉じた後も音声とメディア操作を維持します。
- `alarms`。ユーザーが有効化した定時巡回と番組生成を開始します。
- `tabs`、`tabGroups`、`scripting`。巡回タブの開閉・整理、指定タブの URL の取得、許可済みページからの素材抽出、AI Studio や公開フォームの操作補助に使用します。
- ホスト権限。Google Gemini API と OpenAI API に HTTPS でアクセスします。それ以外のサイトは、機能の実行時に必要な HTTPS ホストのアクセスを求めます。

## 5. 保持・削除・問い合わせ

ローカルデータは個別削除または Chrome から拡張機能をアンインストールするまで保存されます。外部サービスに送信したデータや端末に書き出したファイルは、送信先や端末側で管理してください。

問い合わせは [agentCast の GitHub Issues](https://github.com/kamihicouki/agentCast/issues) へお願いします。API キーや非公開の素材は投稿しないでください。
