# Final QA — the ten principles, made checkable

Run after the subtraction pass. Every box must check. The principles are the verdict layer; the tokens got you here.

1. **Innovative** — Did the layout emerge from this content's functional grouping, or was a template filled in? (Zones must map 1:1 to real task groups.)
2. **Useful** — Can every element on screen answer "what task do I serve"? Anything that answers "I look nice" was missed in the subtraction pass.
3. **Aesthetic** — Is ≥95% of the surface neutral? Is the spacing ratio (zone gap = 2–3× inner gap) intact everywhere?
4. **Understandable** — Is every control's state visible at rest, without hover or interaction? Would a first-time user know what the accent element does within one second?
5. **Unobtrusive** — Does chroma appear only on operations? Does nothing animate without a user cause?
6. **Honest** — No fake progress, no manufactured urgency, no dark patterns, no implied capabilities the product lacks?
7. **Long-lasting** — Zero effects from the anti-patterns "longevity" list? Would this screen look reasonable in 1995 and 2035?
8. **Thorough down to the last detail** — One radius everywhere? All UI text lowercase? Tabular numerals on every figure? Hairlines exactly 1px?
9. **Environmentally friendly** (screen translation) — Lean: system-font fallbacks work, no multi-MB hero media, motion respects `prefers-reduced-motion`.
10. **As little design as possible** — Was the subtraction pass actually run? Try removing one more element right now; if nothing breaks, remove it and run this list again.
