what this is

Rams' ten principles are a verdict, not a recipe. This skill is the recipe: every rule is reverse-engineered from Braun hardware — SK4, TP1, ET66, T3, TG60, regie 510 — and Vitsoe 606, then quantified into hex values, a type scale, spacing ratios and a forbidden list, so an agent can produce UI that reads as Braun rather than as "generic minimal".

The ten principles come back at the end, where they belong: as the QA gate.

this page is built entirely from the skill's own tokens. it is the specimen, not a mock-up of one.

install

claude code — drop the folder at one of these paths:

~/.claude/skills/rams-braun-ui/     # personal
.claude/skills/rams-braun-ui/       # project

claude.ai — settings → capabilities → enable code execution, then customize → skills → “+” → upload this folder as a zip.

Then say use the rams-braun-ui skill to build …, or just ask for “rams style” / “braun style” / “拉姆斯风格”.

on first runs, don't add your own style adjectives (“minimal”, “premium”…). let the skill drive alone — then tighten the tokens, not the prompt.

中文

这不是把拉姆斯十大原则复述一遍——十大原则是验收标准，不是生成规则。这个 Skill 把 Braun 产品（1955–1995）的设计语言逆向成了可执行的硬规格：色板 hex、字号表、间距比例、圆角、禁令清单，最后才让十大原则回到它该在的位置——QA 层。

装进 Claude / Claude Code，说一句“用拉姆斯风格做个页面”即可。这个页面本身就是它的输出样本。

hex values and measurements are derived from photographic reference of braun products; they are internally consistent approximations, not official braun specifications.

an homage to the work of dieter rams and the braun design department. unaffiliated with braun gmbh or vitsoe. mit licensed.
